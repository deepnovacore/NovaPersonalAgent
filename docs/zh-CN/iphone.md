# 在 iPhone 与 Android 上使用 Nova（NovaCore）

移动端伴侣应用 **NovaCore**（`clients/flutter`）同时支持 **iOS 与 Android**。你可以将其作为 **Client** 配对到桌面或无头 Host，也可以在手机上创建本地运行的 **独立 Space**。

## 两种 Space 模式

- **Client Space（配对桌面 Host）：** 模型推理、个人记忆、连接器与后台执行器均运行在电脑（固定的 Space Host）上。手机端保存展示缓存，在 Host 在线时进行语音/文字对话与操作审批，离线时将非聊天意图排队等待重连提交。
- **独立 Space（端侧运行）：** 直接在手机本地运行，不依赖桌面 Host 或 Relay。数据、工作区与本地记忆留在本机。独立 Space 不能原地转为 Client；切换模式需要新建 Space，旧数据不迁移。

## 将手机配对到桌面 Host

1. 在桌面端打开 **设置 → Space 与手机** 并创建空间（支持 **Tailscale 自动配置** 或填入自托管 [Relay](../../relay/README.md) 地址）。
2. 在桌面端生成一次性配对二维码。
3. 在 iOS 或 Android 的 NovaCore 中选择 **Client** 并扫描二维码。
4. 核对手机与桌面端显示的完整设备指纹，并在桌面端确认配对。

全新 Host 上第一台经确认的手机将成为该 Space 的 **所有者（Owner）**，可在手机端 **设置 → Host 设置** 中管理模型密钥与飞书登录。你可以随时在桌面端或命令行撤销已配对设备。完整部署与排障说明见 [Space / Host / Client 开发与部署](space-host-client.md)。

## 对话、输入与任务控制

- **语音与文字：** 支持实时语音对话，以及在 Host 管线支持可编辑输入时使用文字输入与听写草稿。
- **任务与审批：** 后台任务在 Host 上执行；需要权限确认时手机端会弹出操作详情供你批准或拒绝。断开手机连接或退出应用不会取消电脑上正在运行的任务。
- **独立空间本地记忆：** 在手机独立 Space 中，你可以明确要求 Nova 记住或忘记简短事实；该存储仅限当前 Space 本地使用，并已排除出系统云备份。

## 使用限制

- Client 聊天需要 Host 在线；Host 离线时聊天请求会立即失败，不会静默排队。
- 暂不支持手机端摄像头接入、屏幕共享与后台语音唤醒词。
- Host 丢失即对应 Client Space 丢失（不提供云端备份或自动主备切换）。
- 旧版原生 iOS 源码保留在 `clients/ios/Nova`，当前跨平台移动端开发统一基于 `clients/flutter`。
