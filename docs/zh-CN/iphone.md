# 在 iPhone 与 Android 上使用 Nova（NovaCore）

移动端伴侣应用 **NovaCore**（`clients/flutter`）同时支持 **iOS 与 Android**。你可以将其作为 **Client** 配对到桌面或无头 Host，也可以在手机上创建本地运行的 **独立 Space**。界面支持中文与英文。

## 两种 Space 模式

- **Client Space（配对桌面 Host）：** 模型推理、个人记忆、连接器与后台执行器均运行在电脑（固定的 Space Host）上。手机端保存展示缓存，在 Host 在线时向 Host 发送文字对话，查看任务并处理审批，离线时将你对自己事项的修改排队等待重连提交。
- **独立 Space（端侧运行）：** 直接在手机本地运行，不依赖桌面 Host 或 Relay。数据、工作区与本地记忆留在本机。独立 Space 不能原地转为 Client；切换模式需要新建 Space，旧数据不迁移。

## 将手机配对到桌面 Host

1. 在桌面端打开 **设置 → 设备**。在 **连接方式** 中保持 **Tailscale 自动配置**（或选择 **高级：使用已有 Relay** 并填入自托管 [Relay](../../relay/README.md) 地址），然后点击 **创建空间**。
2. 在 **连接手机** 中点击 **生成一次性配对码**，桌面会显示二维码。
3. 在 iOS 或 Android 的 NovaCore 中新建 Space，选择 **连接 Host**，扫描二维码或粘贴邀请码。
4. 回到桌面端，在 **待连接的手机** 下输入手机上显示的完整指纹，点击 **确认绑定**。

全新 Host 上第一台经确认的手机将成为该 Space 的 **所有者（Owner）**。只有所有者可以在手机上批准 Host 的操作，并管理 Host 设置、模型密钥与飞书登录。你可以随时在桌面端或命令行撤销已配对设备。完整流程与网络要求见 [Space / Host / Client 开发与部署](space-host-client.md)。

## 两种模式各提供什么

| 能力 | Client Space | 独立 Space |
|---|---|---|
| 文字对话 | 支持，由 Host 回复；需要 Host 在线 | 支持，在手机上运行 |
| 听写输入（按住说话，编辑后发送） | 支持；使用手机上配置的语音识别转成草稿，不会自动发送 | 支持 |
| 实时语音 | 支持，前提是 Host 的 relay 提供媒体转发：聊天页会出现通话按钮。默认仅所有者可用，经 Host 的 relay 端到端加密中转；听写作为备选 | 支持 |
| 任务 | 查看 Host 上的任务与执行动态，需在电脑上继续处理 | 在手机上运行 |
| 执行器操作审批 | 支持，仅所有者：在手机上允许或拒绝 | 不适用（没有 Host） |
| 时间线、个人资料、资讯、待办、想法、目标 | 支持，展示 Host 数据并缓存，离线可查看 | 支持，来自本地数据 |
| 定时任务 | 在 Host 上运行 | 在手机上运行 |
| 连接器 | 显示飞书状态，所有者可调整其设置；飞书授权需在电脑上完成。“手机采集与授权”页用于手动提交内容 | 手机上的连接器页面 |
| Host 模型密钥与设置 | 仅所有者 | 不适用 |
| 虚拟屏幕上的手机操作 | 不支持 | 仅 Android |
| 记忆 | 由 Host 保存 | 仅限本 Space；可让 Nova 记住或忘记简短事实 |

### 手机拍照（`camera.capture`）

Client 没有持续的摄像头画面。Host 可以请求已配对的手机拍一张照片，且仅在以下条件都满足时才会执行：

- NovaCore 在前台，且请求未过期（最长 60 秒）；
- 已授予系统相机权限；
- 由你自己在系统相机界面拍照，取消即视为拒绝。

NovaCore 会返回一张 JPEG（最长边不超过 640 px，小于 64 KiB）以及 Host 提供的提示语（最多 500 字符）。不会在后台拍摄，相同请求 ID 重发也不会再拍第二张。同一通道还承载日历读取（iOS 与 Android）和创建提醒（仅 iOS；Android 会明确返回不支持）。

## 对话、输入与任务控制

- **文字与听写：** 可直接在输入框打字，也可按住麦克风按钮说话，松开后转为文字，编辑草稿后再发送。Client 聊天需要 Host 在线；Host 离线时发送会失败，不会自动重发。
- **任务与审批：** 后台任务在 Host 上执行；需要权限确认时手机端会显示操作详情，所有者可选择允许或拒绝。已过期或已被处理的审批会提示，不会执行任何操作。断开手机连接或退出应用不会取消电脑上正在运行的任务。
- **独立空间本地记忆：** 在手机独立 Space 中，你可以明确要求 Nova 记住或忘记简短事实；该存储仅限当前 Space 本地使用，并已排除出系统云备份。

## 使用限制

- Client 聊天需要 Host 在线；Host 离线时聊天请求会立即失败，不会静默排队。
- Client Space 的实时语音需要 Host 在线且 relay 提供媒体转发，默认仅所有者可以发起。没有通话按钮时请使用听写。详见 [Space / Host / Client 部署与使用](space-host-client.md#实时语音可选)。
- 暂不支持持续的手机摄像头、屏幕共享与后台语音唤醒词。
- Host 丢失即对应 Client Space 丢失（不提供云端备份或自动主备切换）。
- 旧版原生 iOS 源码保留在 `clients/ios/Nova`，当前跨平台移动端开发统一基于 `clients/flutter`。
