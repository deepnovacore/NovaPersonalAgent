# Nova Personal Agent v1.0.0

v1.0.0 is the first major open-source release of Nova Personal Agent (`GPL-3.0-or-later`).

## Highlights

- **Space / Host / Client architecture:** Fixed-role Space ownership with end-to-end encrypted communication over a self-hosted `relay` or automatic Tailscale Serve setup, plus `push-gateway` support for APNs / FCM wakeups.
- **Cross-platform mobile companion (NovaCore):** Unified Flutter client (`clients/flutter`) for iOS and Android supporting both paired Client Spaces and on-device Standalone Spaces.
- **React-based Desktop Workbench:** Rebuilt desktop renderer (`clients/desktop/src/renderer`) integrating Timeline, Ideas, Goals, Feeds, Tasks, Profile, and multi-conversation modes (`Chat`, `Plan`, `Build`, `Delegate`).
- **Expanded executors:** Coding over Codex app-server and ACP (`OpenCode`, `CodeBuddy`, `Pi`, `DeepSeek Harness`), Build-integrated and standalone Computer Use, supervised Mobile Use (`mobile.run` via Midscene SDK), and independent Loop Camera monitoring.
- **Ledger-authoritative personal memory:** Unified local memory ledger (`workspace-graph.sqlite`) with optional `mem0` / `voicemem` recall composition, explicit consent separation (source read vs. model processing), and forget/purge controls.

## Upgrade & compatibility notes

- **Space data model:** v1.0.0 introduces the Space / Host / Client model. Creating a Space starts with fresh, isolated `space/` data (`0700`); existing pre-Space data is not migrated automatically.
