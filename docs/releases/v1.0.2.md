# Nova Personal Agent v1.0.2

v1.0.2 is a fix-and-polish release on top of v1.0.0. (The npm-only `nova-personal-agent@1.0.1` was a CLI patch for v1.0.0; there is no separate v1.0.1 app release.) It brings realtime voice and approvals to phones paired with a desktop Host, finishes the move to the `nova-personal-agent` identity, and fixes many reliability, security and CI issues found in the v1.0.0 review.

## Highlights

- **Realtime voice in a Client Space:** a phone paired with your desktop Host can hold a realtime voice call through the Host, end-to-end encrypted over the relay. The relay the desktop creates over Tailscale serves voice by default; a self-hosted relay needs `media.enabled`. Voice is owner-only by default, and dictation stays available as the fallback.
- **Approvals and dictation on phones:** executor approval requests from the Host appear as cards in the Client Space chat and task views (owner only), and the composer supports hold-to-dictate.
- **English Client Space:** every Client Space screen, panel and notification follows the phone language.
- **Coding without Codex:** coding readiness follows the selected backend, so ACP backends (OpenCode, CodeBuddy, Pi, DeepSeek Harness) work without a Codex install. `npa doctor` checks the voice keys of the provider you chose.
- **Understanding without OpenRouter:** the understanding pipeline uses your configured model gateway when no OpenRouter key is set.

## Fixes

- Space: a phone only trusts a new key epoch from a Host-signed key delivery, and a revoked phone re-pairs with a fresh identity. The Host keeps a bounded, replay-safe receipt history instead of stopping at 10,000 operations. Idle relay polls no longer write to disk, and login challenges are capped per device.
- Desktop: the camera permission check works on macOS, Windows and Linux. The bare global Control+M / Control+L shortcuts are gone. The schedule editor no longer loses edits, including quick weekday toggles.
- Memory: the Markdown repository safety check no longer fails when Git removes a temporary lock file mid-scan.
- Purging data now also removes the notifications tied to that evidence.
- Mobile setup no longer offers localhost model presets that cannot work on a phone.

## Removed

- **AutoGLM executor:** removed. A leftover `AUTOGLM_*` setting or `EXECUTORS=autoglm` now stops startup with a clear error instead of being ignored. Use the supervised Mobile Use executor instead.
- **Loop Camera:** its settings are hidden in this release while the feature is reworked.

## Upgrade & compatibility notes

- **Product identity and local data:** The desktop app ID is now `ai.deepnovacore.nova-personal-agent` (formerly `ai.deepnovacore.nova-audio-agent.orb`). New installs keep local data in `~/.nova-personal-agent` and use the `Nova Personal Agent` profile. Existing installs keep working from `~/.nova-audio-agent` and their existing desktop profile with no step required; nothing is moved automatically. Moving the data is optional: quit Nova and run `npa migrate-data --dry-run` to see what would move, then `npa migrate-data`. It renames entries on the same volume without copying or overwriting, and leaves `~/.nova-audio-agent` as a link to the new folder. See [Local data location](../en/configuration.md#local-data-location).
- **Re-grant camera and microphone on macOS:** macOS ties camera, microphone and screen-recording permissions to the app ID, so 1.0.2 asks again on first use. macOS may also ask once for Keychain access to the existing `… Safe Storage` item; choose **Always Allow** to keep your saved keys. On Windows the installer upgrades the existing installation in place; pinned taskbar shortcuts from older builds may need to be pinned again.
- **Unsigned desktop builds:** the macOS, Windows and Linux apps are unsigned, as in v1.0.0. On macOS, remove the quarantine flag as described in [Getting started](../en/getting-started.md).
- **Android:** the APK is a sideload build for arm64.
- **Tailscale machine name:** the relay a desktop Host Space creates over Tailscale is tied to the Mac's Tailscale machine name at creation time. If you renamed the machine since, phones show "cannot reach relay"; rename it back in the Tailscale admin console (and flush the macOS DNS cache if needed). A recovery flow is planned.
