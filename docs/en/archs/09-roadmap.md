# Roadmap

Nova v1.0.0 delivers dual-brain realtime voice and text interaction, a React-based desktop Workbench, multi-backend coding (Codex and ACP agents including OpenCode, CodeBuddy, Pi, and DeepSeek Harness), supervised Computer Use and Mobile Use (`mobile.run`), independent Loop Camera monitoring, personal memory with ledger-authoritative recall, and end-to-end encrypted Space / Host / Client connectivity across desktop and mobile (iOS & Android). See the [support matrix](../support-matrix.md) for current compatibility.

The next directions after v1.0.0 are:

- **Native duplex voice models.** Evaluate end-to-end full-duplex speech models (such as MiniCPM-o and PersonaPlex) behind explicit capability contracts.
- **Broader connectors and personal sources.** Extend beyond the current Google (Gmail/Calendar), macOS Calendar/Apple Mail, and Feishu sources to additional read-only personal accounts and services.
- **Richer mobile and cross-device experience.** Expand real-device push notification coverage, standalone mobile memory/workspace capabilities, and low-latency encrypted relay optimizations.
- **Customizable skins and desktop HUD.** Mature the experimental orb-skin and transparent desktop visor specifications into stable, contributor-friendly extension formats.

These are planned directions, not currently supported integrations or release-date commitments. Each capability will go through explicit permission, trust-boundary, and compatibility verification.
