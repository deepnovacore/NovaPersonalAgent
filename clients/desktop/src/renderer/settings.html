高级配置

当前需要在启动环境中选择 computer 执行器，并配置 GUI 模型和目标显示器。整屏模式仅支持一个显示器。

EXECUTORS=computer,codex
COMPUTER_DISPLAY_ID=0
EXECUTOR_BASE_URL=你的 GUI 模型地址
EXECUTOR_MODEL=模型名称
EXECUTOR_MODEL_FAMILY=qwen3-vl
EXECUTOR_API_KEY=模型密钥

Windows 的显示器 ID 使用其 DISPLAY 名称；系统没有 macOS 的辅助功能授权开关。修改启动配置后重启 Nova。
