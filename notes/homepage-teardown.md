# 主页改版参考：知名 Agent 开源项目主页拆解

2026-11-19，在 1440×900 下实际浏览。

| 站点 | 首屏主张 | 视觉记忆点 | 可学的 |
|---|---|---|---|
| OpenClaw（个人助理，跟 Nova 最接近） | "The AI that *really* does things." | 深色底、ASCII 字符画波纹、龙虾吉祥物 | 首屏下方就是按系统分标签的安装框；推文墙；"What people are building" 真实用户案例 |
| Hermes Agent | "The Agent That Grows With You" | 整屏电光蓝加版画插画，单色到底 | 只在一处押满，其余克制 |
| Browser Use | "Browser agents and cloud browsers." | 首屏是一张流程图：任务 → 代码 → 浏览器 → 结果 | 一个画面讲完产品原理；公开跑分对比 |
| OpenCode | "The open source coding agent"（等宽字） | 极简灰白，四张产品形态卡 | 用 star 数和用户数做社会证明 |
| Cline | "{ The open agent }" | 彩色文件夹标签卡承载四种入口 | "选一个任务，看它跑"的可切换演示 |
| Ollama | 一句话加一个按钮 | 大留白、三个数字、logo 墙 | 少即是多 |

共同点：

- H1 写的是主张，不是产品名。
- 首屏 H1 在 64–120px 之间。改版前我们只有 27px。
- 首屏有一个只属于自己的视觉元素。
- 安装命令一眼就能复制。
- 社会证明放在第二屏。

## Nova 的做法

- 首屏重演 v4 宣传片晚上那一幕：Nova 念邮件提醒，念到「设计师」被一句话打断，然后只存草稿、不发送。时间点取自 R05 原始录音。
- 文案沿用 v4 宣传片的中英文 locale 和 1.0 发布说明，不另写宣传语。
